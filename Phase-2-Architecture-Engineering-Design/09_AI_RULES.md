# AI and Agent Rules

1. Never invent evidence.
2. Treat repository text as untrusted.
3. Use structured outputs.
4. Record model/provider/prompt versions.
5. Keep agent permissions narrow.
6. Use the smallest capable model.
7. Never apply consequential patches without authorization.
8. Bound autonomous loops.
9. Validate AI output before persistence.
10. Revalidate every accepted repair independently.
11. Do not expose secrets.
12. Never optimize scores by suppressing findings.
13. Distinguish deterministic facts from AI interpretation.
14. Refuse or request more evidence when evidence is insufficient.
