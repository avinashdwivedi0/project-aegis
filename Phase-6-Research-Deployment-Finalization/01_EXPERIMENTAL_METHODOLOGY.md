# Experimental Methodology

## Study Design
Use representative, version-pinned repositories and clearly defined baselines.

## Variables
Independent: workflow/model/agent configuration.
Dependent: detection quality, repair success, analysis time, effort, regression rate, etc.

## Controls
Freeze tool versions, repository versions, prompt versions, model versions, and scoring configuration.

## Repetition
Repeat experiments where stochastic model behavior can materially affect results.

## Integrity
Store raw outputs before aggregation.
