# Demo Plan

## 5–10 Minute Flow
1. Create project.
2. Import repository.
3. Start analysis.
4. Show project understanding.
5. Show findings and evidence.
6. Show AI explanation.
7. Generate repair proposal.
8. Review diff.
9. Approve repair.
10. Re-run validation.
11. Show before/after metrics.
12. Export report.

Demo must use a known, reproducible repository and a prepared fallback recording/screenshots.
