# Project Charter

## Working Title
AI Software Quality Assurance Platform

## Vision
Build a web platform that acts as an AI-assisted software quality engineer: it understands a software project, gathers objective evidence from analysis tools, explains risks, prioritizes findings, and assists with safe code repair.

## Mission
Reduce fragmented software-quality review effort through an evidence-first, multi-agent workflow.

## Research Orientation
The project is simultaneously:
1. A software engineering system.
2. A multi-agent AI research prototype.
3. An experimental evaluation platform.

## Core Principles
- Evidence before AI opinion.
- Human approval before consequential changes.
- Reproducibility.
- Security by isolation.
- Measurable claims.
- Controlled scope.

## Stakeholders
- Student developer/researcher
- Faculty supervisor
- Developers
- QA/security reviewers
- Research-paper reviewers

## Success
A representative repository can be analyzed end-to-end, findings are traceable to evidence, repair suggestions are reviewable, approved repairs can be independently revalidated, and experiments produce reproducible results.
