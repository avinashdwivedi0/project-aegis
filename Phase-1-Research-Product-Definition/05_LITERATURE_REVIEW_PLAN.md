# Literature Review Plan

## Themes
1. AI for Software Engineering
2. LLM-based Code Review
3. Automated Program Repair
4. Static Analysis
5. Software Security Analysis
6. Automated Testing
7. Multi-Agent Systems
8. Explainable AI

## Search Sources
Use authoritative academic indexes and publisher libraries available through the institution.

## Extraction Fields
- Citation
- Year
- Problem
- Method
- Dataset
- Model/tool
- Evaluation metrics
- Results
- Limitations
- Relevance to this project

## Target
Start with 25–40 relevant papers, then narrow to the strongest evidence.

## Integrity Rule
Do not invent citations, datasets, results, or research gaps. Every literature claim must be traceable to its source.
