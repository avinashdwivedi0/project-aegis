# Objectives and Scope

## Objectives
1. Design a modular multi-agent architecture.
2. Analyze representative software repositories automatically.
3. Normalize findings from heterogeneous analyzers.
4. Provide evidence-grounded explanations and prioritization.
5. Generate reviewable repair suggestions.
6. Re-run relevant checks after approved repairs.
7. Evaluate detection, repair, efficiency, and reliability metrics.

## Scope
### In
Web applications, repository analysis, selected languages/frameworks, deterministic analysis, AI interpretation, repair suggestions, dashboard, experiments.

### Out of V1
Universal language support, unrestricted autonomous coding, enterprise-scale orchestration, mobile applications, model training.

## Scope Rule
A feature enters V1 only if it supports the research questions, is feasible within the project schedule/resources, and can be evaluated.
