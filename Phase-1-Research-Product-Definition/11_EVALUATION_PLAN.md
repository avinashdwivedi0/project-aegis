# Evaluation Plan

## Evaluation Layers
1. Deterministic analyzer correctness.
2. Finding normalization correctness.
3. AI interpretation quality.
4. Repair effectiveness.
5. End-to-end system performance.

## Candidate Metrics
- Precision
- Recall
- F1 where ground truth exists
- False-positive rate
- Repair success rate
- Regression rate
- Analysis duration
- Human effort/time
- Quality-score change

## Baselines
Compare against selected deterministic tools and, where scientifically appropriate, a non-agent or single-model baseline.

## Reproducibility
Record repository version, tool versions, model/provider, prompt version, configuration, raw outputs, and evaluation scripts.
