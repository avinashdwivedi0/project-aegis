# Master Project Rules

1. Research goals control feature scope.
2. No feature is accepted merely because it is impressive.
3. Every major claim must be experimentally defensible.
4. Deterministic tools provide objective evidence wherever possible.
5. AI output is untrusted until validated.
6. Repository code is untrusted input.
7. Uploaded code executes only in isolated workers.
8. Human approval is required for consequential modifications.
9. Repairs must be independently revalidated.
10. Prompts, models, tools, scores, and experiments are versioned.
11. No fabricated citations, results, benchmarks, or metrics.
12. Do not hide findings to improve scores.
13. Prefer modularity over unnecessary agent proliferation.
14. Keep Version 1 achievable for a single student.
15. Defer non-essential features to future phases/versions.
16. Keep documentation synchronized with implementation.
17. When another AI tool is better suited, recommend it explicitly and explain why.
18. If a proposed decision is technically weak, challenge it with evidence and alternatives.
