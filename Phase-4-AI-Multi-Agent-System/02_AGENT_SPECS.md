# Agent Specifications

## Project Understanding
Input: repository metadata and discovery artifacts.
Output: project map, framework, build/test commands, dependencies, risks.

## Quality Analysis
Input: quality findings + source evidence.
Output: explanation, priority, recommendation.

## Security & Testing
Input: security/dependency/test evidence.
Output: interpretation, safe test recommendations, priority.

## Repair
Input: finding + evidence + relevant source.
Output: candidate patch, rationale, expected effect, validation plan.

## Reporting
Input: validated findings and quality snapshots.
Output: structured report sections and recommendations.
