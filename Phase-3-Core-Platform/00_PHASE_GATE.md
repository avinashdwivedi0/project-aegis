# Phase 3 — Core Platform

## Goal
Build the non-AI engineering foundation: authentication, project ingestion, sandboxed workspaces, job orchestration, analyzers, finding normalization, and persistence.

## Exit Criteria
A representative repository can enter the system, be analyzed by deterministic tools in isolation, and produce normalized findings through an observable asynchronous job.

## Gate
AI orchestration is added only after the deterministic pipeline is stable.
