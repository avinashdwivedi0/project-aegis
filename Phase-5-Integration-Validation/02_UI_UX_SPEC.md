# UI/UX Specification

## Screens
- Login/Register
- Projects
- Project overview
- Analysis configuration
- Live analysis
- Findings
- Finding detail
- Code/evidence
- Repair diff
- Before/after
- Reports
- Settings

## UX Principles
- Evidence visible near every claim.
- Severity and status unambiguous.
- AI-generated content clearly identified.
- No destructive action without confirmation.
- Progress and partial failures visible.
